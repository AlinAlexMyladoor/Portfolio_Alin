## 🎨 Interactive Experience

The website uses vanilla JavaScript to create interactive UI behavior.

### Loading Experience

```text
Page Load
   ↓
Animated Loading Screen
   ↓
Progress Indicator
   ↓
Portfolio Initialization
   ↓
Interactive UI
```

### Scroll Animations

Sections use the **Intersection Observer API** to trigger reveal animations as content enters the viewport.

### Interactive Cards

Project and content cards respond to mouse movement using CSS 3D transforms to create a dynamic tilt effect.

### Horizontal Project Showcase

The projects section uses scroll position to create a horizontal scrolling portfolio experience.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AlinAlexMyladoor/Portfolio_Alin.git
cd Portfolio_Alin
```

### 2. Run locally

Since this is a static website, it can be opened directly:

```text
index.html
```

For a better development experience, use a local server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
